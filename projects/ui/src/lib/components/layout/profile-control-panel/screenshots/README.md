# Проверка выравнивания панели профиля в PROD

Снимки сделаны в headless Edge на разметке PROD-компонента со скомпилированными SCSS, исходными символами SVG-спрайта и шрифтом Mont. Поведение notification center проверяется отдельно компонентными тестами.

| Ширина  | Центр bell до/после | Центр logout до/после | Центр avatar до/после | Снимок после          |
| ------- | ------------------: | --------------------: | --------------------: | --------------------- |
| 1440 px |      34,5 / 34,5 px |        30,5 / 34,5 px |        34,5 / 34,5 px | [1440](prod-1440.png) |
| 1280 px |      34,5 / 34,5 px |        30,5 / 34,5 px |        34,5 / 34,5 px | [1280](prod-1280.png) |
| 1024 px |      34,5 / 34,5 px |        30,5 / 34,5 px |        34,5 / 34,5 px | [1024](prod-1024.png) |

Внешние размеры обоих SVG до и после — 15 × 17 px. Панель остаётся 164 × 33 px; gap между действиями — 30 px. Индикатор непрочитанного остаётся на прежнем месте.
