# Мета-строка превью новостей

Проверка выполнена на локальном Angular fixture с синтетическими данными. Backend, React, API, пагинация и окно чтения новости не менялись.

## Результат

- Лайк со счётчиком и копирование ссылки собраны в левую flex-группу.
- Просмотры закреплены справа; все элементы находятся на одной горизонтальной оси.
- Иконки лайка, ссылки и просмотров имеют размер 16 × 16 px.
- Числа имеют размер 12 px и `font-variant-numeric: tabular-nums`.
- Нулевой счётчик лайков отображается как `0`.
- Один шаблон используется для новостей проектов и людей.
- Industry-chip проекта перенесён в верхнюю строку рядом с типом новости, поэтому нижняя мета-строка одинакова у обоих типов превью, а отрасль остаётся видимой.
