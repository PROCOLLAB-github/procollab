# Smoke-test после merge в dev

Проверка обязательна на реальном iPhone/iPad с Safari и реальном Android с Chrome, после успешного deploy merge-коммита PR #401 на dev-стенд, перед prod. Сейчас физическая проверка **не выполнена**: доступ к устройствам/сервису устройств, точный URL стенда и тестовый аккаунт ещё не предоставлены. Headless Chrome и viewport/touch эмуляция не считаются выполнением этого пункта.

Перед проверкой записать URL стенда, merge/deploy SHA, дату, имя проверяющего, модели устройств, версии ОС/браузеров и тестовый аккаунт без пароля. Выполнять действия с тестовыми профилями и проектами на dev.

| ------------------------------------------------------------------------------------------- | ---------- | -------------- |
| Вход; drawer; закрытие по фону; возврат/переход между разделами                             | ☐          | ☐              |
| Проекты: список, фильтры, tabs scroll, карточка, создание/сохранение тестового черновика    | ☐          | ☐              |

К каждому найденному дефекту приложить устройство/ОС/браузер, dev SHA, шаги, ожидаемое/фактическое поведение и screenshot/video. Исправлять **отдельным PR в dev**, затем повторять затронутый сценарий на обоих устройствах. Не переводить исправление или UI Kit в prod до успешной физической проверки.

Результат фиксируется отдельно: passed/failed по каждому устройству, ссылки на дефекты и отдельные PR, подтверждение повторной проверки. Этот документ является чек-листом, а не свидетельством выполненного smoke-test.
