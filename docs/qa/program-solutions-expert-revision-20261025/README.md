# QA01: изменение критериев и отзыв экспертной роли

Найден и исправлен пропущенный отказ `not_program_expert`: при потере экспертной роли старая форма оставалась доступной для ввода, хотя сервер запрещал сохранение. Это воспроизведено настоящим POST 403 у синтетического пользователя с двумя ролями — организатора и эксперта. После исправления используется прежнее состояние «Решение недоступно», frame/ввод/предыдущие ответы очищаются. Права сервера и контракт не менялись; новый UI не добавлялся.

Регрессия сначала была красной, после исправления все 9 component tests прошли. Final `npm run test:ci` — **2794 tests/479 files + strict C00 types PASS**; development build и scoped ESLint PASS. C00 остается 1.14.0, 125 schemas/47 operations/185 scenarios. Backend source 30c0d3e не менялся.

## Реальный экспертный путь

В КЧ использовано распределенное оценивание, в хакатоне — открытое; оба с required_evaluators=2. Организатор меняет критерии настоящим PUT во время локального ввода эксперта. Роль и время меняются только контролем новых fixtures; HTTP ответы не подменялись. Подтверждение один раз задержано перед отправкой, затем передано настоящему API.

## Происхождение и ограничения

[До исправления](browser-before-checks.json) сохраняет настоящий product FAIL на КЧ программы 21; хакатон 22 был подготовлен, но baseline остановился на первом дефекте. Это не baseline обеих форм.

Итог составлен из нескольких сохраненных запусков. Первый post-fix полностью проверил КЧ, затем harness ошибочно использовал страницу капитана для хакатона. Повтор завершил все основные проверки хакатона, но второму актеру не загрузился dynamic chunk при HTTP 200; причина не установлена, исходная JavaScript ошибка сохранена. Отдельный read-only прогон с настоящим login/returnUrl завершил изоляцию ролей обеих программ без сброса данных. У него 0 JavaScript errors; это не утверждение об отсутствии ошибок во всех попытках. Harness также уточнил ожидание onboarding modal и существующий placeholder «Не указано». Эти поправки не являются исправлениями продукта.

Полные raw wire, FAIL/partial reports и screenshots сохранены локально в `design-artifacts/program-solutions-20261024/qa01-expert-revision`; [manifest](local-artifacts.json) содержит SHA256. В Git включены компактные checks и независимый verifier; credential manifests/JWT не включены. [Build before](build-before.json)/[after](build-after.json) меняют только API/WS origins одного generated chunk в копии build. Source environments, controls/layout/SCSS, D00/D01 и API сохранены. Remote avatars блокировались local network guard, screenshots могут отражать текущую вертикальную прокрутку. Полные desktop/a11y/zoom/production CDN не заявляются.
