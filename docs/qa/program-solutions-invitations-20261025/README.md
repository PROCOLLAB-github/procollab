Проверены КЧ и хакатон на настоящих Angular, Django и PostgreSQL. Два конкурентных приглашения разным людям резервируют одно последнее место. Проверены границы роли, недоступные получатели, сохранение ввода при ошибке, изменение роли с конфликтом версий и отзыв. Продуктовый код этого checkpoint не менялся. Общие QA01/REL01 остаются открытыми.

## Воспроизводимость и ограничения

Три начальных наблюдения гонки не доказывали одновременное ожидание двух запросов: сначала поиск `FOR UPDATE` не учитывал обрезку `pg_stat_activity.query` до 1 KiB; затем наблюдался один worker; третий монитор искал только прямого блокировщика. Финальный монитор учитывает транзитивные `pg_blocking_pids`: второй запрос может ждать первый, который ждет контроллер. Pending от неудачных наблюдений отозваны обычными DELETE 204; решение не удалялось и не создавалось заново. Все три recovery reports сохранены.

Начальный browser harness ожидал 204 для удаления участника, хотя C00 возвращает 200 с обновленным решением. Другие частичные запуски исправили управление фокусом открытых подсказок и ожидание Angular DOM. Первая съемка адаптива захватила refresh без строки приглашения. Она сохранена отдельно; финальный прогон дожидается роли длиной 128 на каждой ширине и подтверждает ее наличие в JSON отчета. Продуктовых исправлений по этим наблюдениям не потребовалось. Исходные FAIL и отчет до уточнения ожиданий сохранены локально и захешированы. Шесть скопированных evidence JSON равны исходникам по содержимому; raw browser reports в Git не дублируются.

Скриншоты и raw artifacts находятся в `design-artifacts/program-solutions-20261024/qa01-invitations`; [manifest](local-artifacts.json) содержит их SHA256 и хеши использованных helpers. Remote avatars блокировались локальной сетевой политикой. Полные desktop flows, a11y/zoom, нагрузка, production CDN, организаторский/публичный UI и весь первый выпуск этим checkpoint не закрыты.
