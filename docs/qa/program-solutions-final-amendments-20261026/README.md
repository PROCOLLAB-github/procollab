# Финальные правки заявок и публичных решений

Пользователь26.10.2026 утвердил оставшийся дизайн заявок с тремя поправками и прямо указал не ждать следующего согласования. Этот checkpoint реализует их в Angular. Общий первый выпуск остается в работе: AC18/AC19 не закрыты, AC21 относится к отдельному BE10. PR остается draft.

## Поведение

- Только у solution-программы прежний пункт управления «Проекты» называется «Заявки». Порядок семи разделов сохраняется. Новая таблица использует существующие management styles, RowActions, поиск, фильтры, выбор и пагинацию; содержит восемь колонок без «Презентации».
- При открытии меню строки загружаются действительные материалы решения. Сохраненная презентация открывается прямой безопасной ссылкой в новой вкладке. Отсутствующий файл не подменяется ссылкой на Project. Название решения открывает материалы, «Посмотреть команду» — вторую вкладку заявки.
- Смена кейса содержит выбор, краткое объяснение сохранения материалов/команды/оценок, число снимаемых назначений без оценок и подтверждение на одном экране. Preview запрашивается автоматически. Применяется только актуальный подписанный токен для выбранного решения и кейса; ошибка сбрасывает токен, сохраняя выбор. Отдельного экрана/кнопки просмотра последствий нет.
- Подключены реальные list/filter/XLSX, readonly материалы/команда/история, preview/apply сдачи/архива/исключения участника и назначения по выбранным solution IDs. Компоненты не создают отдельную сущность команды и не подставляют solution IDs в Project API. Из общего expert workspace используются только roster/revision; назначения идут через solution allocation API.
- Публичный пункт «Решения» находится в существующем месте «проекты-участники» после разделителя действий программы. Старый условный Project branch сохранен. Шапка использует существующий Detail widget. Два точных read-only маршрута опубликованных решений доступны без office shell и аккаунта; остальные office routes продолжают использовать AuthRequiredGuard.
- Материалы и принятый состав читаются исключительно из published allowlist API. Приватный редактор не используется как fallback. Неконкурсные сохраненные решения доступны по существующему publisher; правила конкурсных несданных черновиков не менялись.

Контракт остается C00 **1.21.0 /156 schemas /59 operations /305 scenarios**. Backend, миграции, данные существующих программ и режимы хранения не менялись. В этом checkpoint нет merge/deploy/переключения реальных программ.
