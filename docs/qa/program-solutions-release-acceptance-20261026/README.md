QA01: **25 обязательных AC PASS**, AC21 вынесен в отдельный BE10 по исходному плану. REL01: **локальная репетиция включения и отключения нового создания PASS**. Код первого выпуска готов к интеграции в dev; merge, развертывание и включение реальных программ в этот отчет не входят.

## Итоговое поведение

- ProgramSolution хранит заявку, материалы и команду внутри нее. Project для новой заявки не создается. «Решение» и «Команда» остаются вкладками одной заявки; действующие поиск участника, свободная роль и переходы приглашений сохраняются.
- Организатор получает реальные списки, сводки, кейсы, покрытие полей, назначения, результаты и Excel из API решений. Solution IDs никогда не передаются в Project API. Из существующего expert workspace используются только roster/revision, а не проектные счетчики.
- Результаты используют существующее представление, формулу и детализацию критериев. Для решений ссылка открывает решение этой программы. Нулевой балл и False остаются оценками, готовность задает сервер. Неконкурсная программа сохраняет материалы без требования сдачи и оценивания.
- Напоминание отправляется после серверного preview только по его токену. Изменение выборки, поиск и смена программы отменяют старые ответы; повторное нажатие и закрытие во время записи блокируются.
- Административная смена кейса, исключение участника, удаление регистрации и архив доступны по согласованным исключениям после сдачи. Материалы, оценки и цепочка before/after snapshots остаются в истории. Архив исключается из active/expert/public readers без физического удаления.
- Публичные решения находятся в самой программе, в прежнем месте кнопки «проекты-участники». После окончания публикуются сданные конкурсные и сохраненные неконкурсные работы при включенной публикации. Конкурсный черновик закрыт. Регистрационные ответы, оценки и pending invitations не попадают в публичный DTO.
- Семь разделов управления и старые Project branches сохранены. Прежние программы не переключаются автоматически; BE10 не запускался.
