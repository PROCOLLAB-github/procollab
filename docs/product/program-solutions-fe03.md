# FE03: редактор и просмотр решения

Первая вкладка рендерит настроенную форму без проектных разделов, вторая сохраняет согласованный сценарий команды и приглашений. Scoped facade держит ввод на уровне заявки, поэтому переключение вкладок и обновление состава не сбрасывают ответы. Общее действие «Сохранить черновик» доступно из обеих вкладок. Незаполненные обязательные поля допустимы до сдачи; кейс не выбирается автоматически. Значения 0 и false отличаются от отсутствия ответа.

PATCH отправляет обе актуальные ревизии и только измененные ответы; нет автоматического повторения записи. После version/form conflict выполняется GET: локальные изменения сохраняются по стабильным ID, неизмененные поля получают серверные данные. Удаленный или изменивший тип локальный ответ остается видимым и требует явного разрешения перед сохранением. При потере прав показывается серверный просмотр и доступная для копирования локальная версия. Переход к другой заявке отменяет старые запросы. Route guard и beforeunload защищают несохраненный ввод; переключение вкладок не вызывает подтверждения.

Файлы загружаются multipart через общий /files/?preserve_original=true по совместимому C00 1.2.0. Клиент проверяет размер/расширение до upload, сервер повторяет проверку при привязке. Результат upload сначала локален и привязывается при сохранении черновика. Очистка снимает только ответ; исходный файл не удаляется. Ошибка upload не теряет остальные поля.

Проверено тестами: 18 целевых проверок facade, wire и маршрутов; неполная форма, 0/false, актуальные версии, отсутствие авто-PATCH, конфликт, измененные поля, потеря права, поздний ответ старой заявки, ошибки файлов, вкладка команды и защита выхода. Общий test:ci прошел: 2544 теста в 465 файлах и строгие TypeScript-примеры C00. Development build, Stylelint измененных SCSS, Prettier 3.8.3 (1940 файлов) прошли. ESLint: 0 ошибок, 6 прежних предупреждений.

Проверено в браузере: реальные Django/PostgreSQL/JWT, формы КЧ и хакатона, сохранение из вкладки команды, реальный конфликт двух вкладок с повторным явным сохранением, PDF и оригинальные PNG байт в байт, очистка без удаления бинарного файла, reload с 0/false и mobile 390 px. Ошибок JavaScript и горизонтального overflow нет. Внешний CDN заменен локальным адаптером только для проверки; upload и привязка выполнялись через реальные endpoints. Mont, segmented tabs и существующие controls сохранены.

Представление сданного снимка и полный шаг подтверждения проходят интеграцию в BE06/FE06. Публикация, эксперт и управление еще не завершены; этот блок не означает готовность всей новой сущности.
