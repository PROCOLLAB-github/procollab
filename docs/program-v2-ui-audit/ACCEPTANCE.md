## 3. Стандартная production-сборка

Команда `NG_BUILD_MAX_WORKERS=2 npm run build:prod` завершилась с exit 0 на окончательном продуктном коде. Переменная ограничивает число workers; настройки production не меняет. Дополнительно проверен непосредственно полученный `dist/social_platform`: 16 заполненных страниц и 30 проверок диалогов/данных на 390/1440 px. API этих браузерных проверок изолирован fixtures.

Причины блокеров установлены отдельно:

1. Google Fonts 403: исходный index.html ссылался на внешнюю таблицу Material Icons. Cloud proxy запрещает этот хост, а production inlining пытался ее скачать. Ссылка присутствовала до задачи; пользователей этого icon font в исходниках нет, действующие иконки — SVG. Удалены только неиспользуемые link/preconnect. Локальные Mont и SVG сохранены, font inlining не отключен.
2. CSS budgets: все пять ошибок воспроизведены на исходном dev `9ef90b58` до изменений. Исходные размеры: management 24,91 kB, experts 24,65 kB, certificates 17,33 kB, analytics 15,07 kB, drilldown 19,57 kB при error limit 15 kB. Общие стили выделены по назначению, повторная генерация foundation устранена, мертвые стили аналитики удалены. Лимит Angular относится к отдельному stylesheet-ресурсу; суммарный CSS компонента не выдается за размер одного файла. Бюджеты, angular.json и зависимости не менялись.

Остались предупреждения существующего toolchain о Sass deprecations, CommonJS, initial warning budget и 2 kB stylesheet warning budget. Ошибок production build нет. Диагностическая сборка из первоначального этапа больше не используется как критерий готовности; ее вспомогательный обходной скрипт удален из итогового checkout.
