## Checked by source

- Проверен весь diff относительно `9ef90b5824b857fe53d52c097e37b279b897d9bf`, включая новые файлы и обоих consumers общих компонентов. `origin/dev` на момент проверки совпадает с базой. Исходная рабочая копия не содержала пользовательских изменений.
- HTTP adapters, ports, domain models, маршруты, guards, backend и зависимости не менялись. Новых API/endpoints, миграций, Project FK в Solution и клиентского переопределения серверных permissions нет.
- Общий roster принимает DTO/выбор/actions и сообщает события родителям. Он не загружает назначения. Подписи состояний общие; tooltip V1 по умолчанию говорит «Проекты», V2 явно передает «Решения».
- Общая сводка оценивания принимает числовые totals и события. Нулевые значения не заменяются отсутствующими; доля незавершенных назначений не округляется до 100%. Возможность V2 открыть пустые назначения сохранена отдельным input.
- Сохранены фильтры и query заявок, debounce, 409/conflict и preview/apply tokens, protected/own-team/eligibility, disabled при busy и права, полученные из API. Выбор при фильтрации V2 сбрасывается, чтобы не применять действие к скрытым строкам.
- Выделенный SCSS roster содержит исходные правила V1. Новый компонент не импортирует весь большой experts.scss; контракт ограничивает распространение стилей.
- Дополнительные найденные маршруты: V1 `management/projects/:linkId/evaluation` использует общий ResultProjectScores; V2 `solutions-rating` и `solutions/:solutionId/evaluation` используют существующие rating-workspace/rating-card и ProjectRating renderer критериев без переноса Project ID. `solutions/new|:id|:id/edit` используют solution-ui/typography и общие поля; `launch`, branding preview и публичные published-solutions используют действующие DS components. Их бизнес-потоки не изменены; отдельная браузерная приемка этих соседних участнических/публичных маршрутов не заявляется.
- Figma: UI Kit, components/variants/states, settings, certificates, experts/distribution, participants/projects/results и секции аналитики исследованы через MCP. Согласование источников Proposed/TEMP Inter и ранних экранов описано в README.
- Impeccable detector выполнен один раз на измененной разметке/SCSS. Единственное предупреждение «img without src» — ложное: существующий Angular `<img [src]="src" [alt]="image.label" />` находится под `@if` валидного URL. Динамическая привязка не распознана статическим детектором; код не менялся ради подавления предупреждения.

## Checked by tests

Настроенный Vitest-набор: 498 файлов, 3089 тестов, 0 failed/pending. Три существующих config exclusions сохранены. После исправления найденной проверки tooltip V1 повторены 65 тестов четырех затронутых файлов; итоговая сводка объединяет последние исходы каждого файла. Новые assertions проверяют filter draft/apply/reset, выбор между страницами и его сброс, Solution IDs распределения, отсутствие обращения к Project при чистом progress presentation и сохранение empty action V2.

Solution contract type check, ESLint для 13 TS, Stylelint для 8 SCSS, Prettier для 22 TS/HTML и diff whitespace — успешны. Подробные команды находятся в VERIFICATION.md. Глобальный pre-commit с автоматическим `lint:scss --fix` не запускался: вместо него выполнены адресные проверки всех измененных файлов, без форматирования остального репозитория.

## Checked in browser

Chromium, настоящее скомпилированное Angular-приложение, изолированные fixtures. Всего **596 финальных проверок**: 140 основных, 395 interactions, 40 states, 5 visual contracts и 16 smoke оптимизированного артефакта. Все успешны. Еще 183 снимка исходной версии сохранены для сравнения. Никакие запросы не направлялись в реальный API.

Проверены поиск/сброс фильтров/выбор, menus, приглашение и кейсы эксперта, Solution assignments/quota/allocation preview, заявка/команда/история и административные preview, результаты/формула/фильтры, вложенный V1-маршрут оценки проекта, семь настроек и PATCH основного раздела, редакторы/preview форм, сертификаты, аналитические списки/экспорт/назначения. Отдельно: пустой roster, 503 с retry, loading, 403, неконкурсные disabled controls, keyboard focus trap/Escape/возврат focus, hover/focus и геометрия общих controls. После обнаружения смещения меню распределения V2 исправлена привязка к строке; новый assertion проверяет границы каждого меню на всех пяти ширинах.

На 70 основных снимках V1 размеры и геометрия сохранены; 60 полностью идентичны, в 10 изменение максимум 0,00063% пикселей. Это не проверка реальных серверных данных и не автоматический pixel match каждого состояния с Figma.

## Checked by build / Not checked

- Обычный `npm run build:prod`: FAILED, Cloud отклоняет скачивание Google Fonts (403).
- Production с отключением только font inlining и исходными budgets: FAILED, пять превышений CSS 15 kB. Они воспроизведены на исходной базе. Management/expert CSS увеличился на 0,09/0,18 kB, набор нарушений не изменился; новые компоненты ниже лимита.
- Диагностический оптимизированный production-артефакт: PASS с `PROGRAM_UI_COMPILE_ONLY=1` и fonts inline false. Исходные настройки сборки не изменены. Этот результат не заменяет стандартный production build.
- Не проверены live V1/V2, реальное сохранение/экспорт/PDF/email, серверные permission и конкурентные транзакции: нет доступа организатора к тестовым программам. Нужен отдельный прогон на реальном тестовом контуре.

Остаточные риски: данные с неизвестными длинными значениями/большой численностью вне fixtures, реальные серверные конфликты, браузеры кроме Chromium. Автоматические tests проверяют существующие контракты, но не заменяют серверную приемку.
