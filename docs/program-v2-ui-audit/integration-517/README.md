Обычный вход не выполнялся, пароль/токен не запрашивались и не искались в файлах. `/auth/users/current/` и 12 read-only управленческих запросов к №39/49 отвечают 401 `Authentication credentials were not provided.` Причина ограничения — авторизация, сеть/CORS работают.
