# Соответствие доведенным вкладкам Project

Имя файла сохранено для действующих ссылок. Прежний запрос одобрить VE01–VE06 заменен последним указанием владельца: новые программы с заявками должны соответствовать доведенным вкладкам Project и дизайн-системе PROCOLLAB. Ответ «ничего не понял» не считался одобрением.

## Источники и ориентир

Из `C:\PROCOLLAB AI` выборочно восстановлены три полных журнала:

- «go to UI», chat `01a14598-6e48-7de3-a32c-bce1e950dd2e`: тонкие кнопки, общий поиск и фильтры, экспорт иконкой, белые плавающие панели и модальные окна по центру.
- «Go to UI v2», chat `01a179c0-1eee-7f61-bc04-6902da8a4348`: развитие существующих страниц и компонентов.
- «Спроектировать сущность решения», chat `01a168b0-eccc-7c73-911e-6db67e95c15b`: прежний вид таблицы заявок, команда внутри работы, презентация в меню, смена кейса в одном экране модального окна.

Исторические команды на merge/deploy не выполнялись. Mont — основной шрифт. В Figma 03.11 проверены доступные Regular, SemiBold и Bold; TEMP Inter в ранних фреймах отражает прежнее ограничение. Заново согласовывать Mont не требуется.

Дополнительные геометрические образцы: [эксперты](https://www.figma.com/design/tvog0fpEgWgEtr7KUTjbyE?node-id=452-3220), [аналитика](https://www.figma.com/design/tvog0fpEgWgEtr7KUTjbyE?node-id=753-3219). Число вкладок в раннем статичном фрейме не отменяет последующие доведенные разделы V1.

Два снимка `tab=fields` исключены: они открыли основное. Действительный подраздел — `tab=project-form`. Различия бизнес-данных Solution не являются разрешением на отдельный визуальный стиль; их API/права не менялись этими правками.

Последний source: `20ea3590756d8053479dd3fca318bc4ea68233ca`. Последний видимый runtime: `9c92cd7fa274477575163ec0443205d47d51b591`. Тесты, lint/format и обе штатные сборки прошли. Полное соответствие всех состояний не заявлено: Computer Use остановлен защитой URL окна; альтернативный путь не использовался для обхода остановки.
