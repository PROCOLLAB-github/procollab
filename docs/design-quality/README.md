# Дизайн-проверка PROCOLLAB

Три набора подключены по запросу владельца для проверки существующей платформы.
Основной сценарий — Operate: человек выполняет задачу в кабинете, списке, форме
или редакторе. Визуальный контракт задают Mont, PROCOLLAB Design System,
существующие компоненты и доведенные экраны Project.

четырех каталогов, проверки исходников продукта продолжают действовать.

## Порядок применения

Результат первого полного прохода: [проверка 04.11.2026](REVIEW-2026-11-04.md).

1. Зафиксировать роль, задачу, primary action и существующий reference каждого раздела.
2. Impeccable: visual/UX critique и отдельные измерения, accessibility,
   responsive, implementation integrity. Для полного critique соблюдать
   независимость Assessment A/B и применимый порядок разрешения делегирования.
3. Taste: review существующего приложения с сохранением palette/type,
   компонентной системы и содержания. Проверять скриншоты и измерения режима app;
   новый draw или перенос app.css не требуется для исправления существующего UI.
4. Emil: оценить необходимость, длительность, easing, origin, interruptibility,
   работу с клавиатуры, pointer/hover gating и reduced motion.
5. Исправить подтвержденные проблемы в существующих компонентах, затем повторить
   затронутые состояния в браузере и выполнить проверки, соответствующие изменению.

## Границы

Скиллы не меняют Angular, API, модель Project/Solution, права, снимки форм,
данные программ или рабочие процессы. Результаты детектора — кандидаты для
проверки, а не автоматическое разрешение заменить брендовые компоненты.
Числа и визуальные предпочтения внешних наборов не переопределяют действующие
tokens и явно согласованный вид продукта.

Настоящие авторизованные сессии используются обычным способом. Пароли, cookies,
токены, Authorization, HAR и storageState не считываются и не экспортируются.
Изменение пользовательских данных, рассылки и выдача сертификатов не требуются
для визуальной проверки. Локальные снимки и измерения остаются вне Git;
в отчеты входят безопасные сводки, источники и ограничения наблюдений.
