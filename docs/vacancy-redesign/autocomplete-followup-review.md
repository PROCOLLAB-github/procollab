# Закрытие двух замечаний Autocomplete

Код: `f1ea89bec92e2e37b89044aa4663b40807ba0be0`, ветка `feat/dev-vacancy-interface-redesign`. Дата: 2026-09-29. PR [#393](https://github.com/PROCOLLAB-github/procollab/pull/393) остаётся draft; перевод в ready — решение ревьюера.

## Воспроизведение до исправления

На исходном `5baf5069` открыта настоящая локальная Angular-сборка с DEV API. URL участников содержал `skills__contains=Angular&speciality__icontains=Front-end&age=18,30&is_mospolytech_student=false`. В 20:29:35 MSK resolver отправил `GET /auth/public-users/?user_type=1&limit=20&offset=0&fullname=`: фильтры отсутствовали, оба поля были пусты, выдача не соответствовала URL.

На профиле при 390 px выбран из DEV-поиска навык «Управление изменениями в организации». Корзина имела ширину 152 px, иконка удаления — **0 px** из-за flex-shrink. Две колонки профиля также создавали горизонтальное переполнение. [Скриншот до исправления](screenshots/autocomplete-followup/profile-390-before.png).

До правок реализации новые проверки дали **4 failed / 10 passed** в двух файлах: полный контракт resolver, восстановление формы при истории браузера, отмена debounce при Back и доступная кнопка удаления. Лог: `tmp/filter-basket-before.log`.

## Исправление

`member-filters.ts` задаёт общий разбор пяти поддерживаемых параметров для resolver, формы и последующей пагинации. Некорректный возраст, массивы query params и неизвестные булевы значения не отправляются в API. `false` сохраняется отдельно от отсутствующего фильтра (`null`). Неизвестные параметры остаются в URL при merge, но не отправляются как фильтры API.

Первый результат берётся из resolver. URL синхронно заполняет обе формы с `emitEvent: false`; это не запускает навигацию или повторную загрузку. Последующие изменения URL отменяют прежний запрос через switchMap и восстанавливают поля. Форма отправляет полный набор фильтров одним потоком; навигации сериализованы. Подтверждение более ранней навигации не стирает последующий ввод. Back/Forward и сброс отменяют debounce и очередь устаревших правок. Сброс принадлежит фасаду обеих форм и работает даже при уже пустом URL, когда Router не эмитит queryParams.

Корзина ограничивает ширину чипа, переносит длинные слова и оставляет несжимаемую нативную кнопку `type="button"` с именем «Удалить навык …». На мобильной ширине/грубом указателе область действия 44×44 px, на desktop — 32×32 px; есть focus-visible и поддержка disabled CVA. Профиль до tablet использует одну колонку. Существующие Mont, цвета, radius и другие глобальные токены сохранены.
