# Процентные веса критериев кейса

Согласовано 11 ноября 2026: сумма весов числовых критериев — 100%, итог кейса —
0–100. [Требования, формула, API и полный AC audit](https://github.com/PROCOLLAB-github/api/blob/codex/weighted-case-criteria-20261111/docs/weighted-case-criteria.md)
находятся в API repo. Квиз и общий рейтинг квиза с кейсом в эту задачу не входят.

## Поведение

В существующем разделе «Оценивание → Критерии» организатор выбирает «Веса
критериев, 0–100», задает проценты в редакторах и сохраняет весь набор. Поле веса
есть у числовых критериев; сумма и валидность шкал проверяются до сохранения и на
сервере. Изменения при 409 остаются в черновике; первая сохраненная оценка
фиксирует критерии и режим. Для прежних программ остается «Сумма исходных баллов».

Эксперт видит вес и вводит исходные баллы. Расчет выполняет API:
`(балл − минимум) / (максимум − минимум) × вес`. Итог команды — среднее полных
оценок экспертов. В результатах видны максимум 100, объяснение и вклады критериев.
Общая форма работает для Project и ProgramSolution; смешивания их сущностей нет.

`scoringMode`, `weightPercent`, `contributions` — добавочные поля. Старый ответ API
без них читается как legacy. C00 1.22.0 и generated solution DTO/fixtures обновлены;
поля запроса оценки и маршруты сохраняются. Сначала устанавливаются API и его
добавочные миграции, затем Angular. Автоматического включения весов нет.

  shared expert form, management adapter, solution contract и solution evaluation.
  TypeScript solution contract check прошел. В API прошли 235 тестов на отдельном
  PostgreSQL; схемы C00 и 307 сценариев проверены валидатором.

  аккаунты, все внешние сервисы заблокированы. Организатор сохранил 40/35/25;
  эксперт через UI отправил 8/7/6, второй через API — 10/8/8. Итоги 71,5 и 88,
  рейтинг 79,75 из 100. Проверены блокировка после первой оценки, формула, выгрузка,
  desktop 1440 px, mobile 390 px без горизонтального скролла, Enter/Escape и
  доступное имя числового поля. Ошибок страницы нет. XLSX после пересчета
  LibreOffice совпал с API.
- Checked by source/design review: расширены существующие controls, cards, modal
  и shared rating form; Mont и текущие tokens сохраняются, нового CSS/анимаций нет.

  визуальной проверки сокращено только название режима, которое обрезалось на
  телефоне. Невыполненных требований к этому расширению формы не осталось.
